# Swift Craft Launcher Assets

A centralized repository for assets and content used by Swift Craft Launcher.

## Contents

- `help/`: macOS Help Book documentation in English, Simplified Chinese, and Traditional Chinese
- `news/`: release announcements and static API data
- `contributors/`: contributor and acknowledgement data
- `imagebed/`: images used by the help documentation
- `releases-notes/`: release notes
- `web/`: legacy website assets, no longer maintained

## Help Documentation

Help pages follow the macOS Help Book HTML/CSS structure. See `help/README.md` for the authoring guide.
