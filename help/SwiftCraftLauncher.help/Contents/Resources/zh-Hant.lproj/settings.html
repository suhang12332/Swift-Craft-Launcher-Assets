啟動器設置

Swift Craft Launcher 提供了多種配置選項，讓您自定義使用體驗。

通用設置

語言選擇

選擇應用語言。更改後需要重啟應用才能生效。（將會導向至系統設定，由系統設定接管語言設定。）

支援的語言：阿拉伯語 (ar)、丹麥語 (da)、德語 (de)、英語 (en)、西班牙語 (es)、芬蘭語 (fi)、法語 (fr)、印地語 (hi)、義大利語 (it)、日語 (ja)、韓語 (ko)、挪威語 (nb)、荷蘭語 (nl)、波蘭語 (pl)、葡萄牙語 (pt)、俄語 (ru)、瑞典語 (sv)、泰語 (th)、土耳其語 (tr)、越南語 (vi)、簡體中文 (zh-Hans)、繁體中文 (zh-Hant)。

主題選擇

選擇主題模式：系統、淺色或深色。

介面佈局風格

設定啟動器介面佈局風格。可選項：classic 和 focused。

classic 適合較傳統的多區域佈局；focused 更強調內容聚焦與簡潔體驗。

啟動器工作目錄

設置啟動器工作目錄。啟動器管理的所有遊戲檔案都將放在此資料夾中。可以重置為預設值。

【重要】更改工作目錄後，原始路徑中的遊戲將不再出現在「遊戲列表」中。建議轉移或重新下載它們。最好在首次打開啟動器時更改工作目錄。

並發下載數量

設置並發下載數量，範圍：1-64。更高的並發性可以提高下載速度，但也會帶來更大的性能開銷。

通用 Sheet 高度限制

設定啟動器中通用 Sheet 彈窗的最大高度限制，用於控制彈出面板在不同螢幕尺寸下的顯示高度。

如果您希望彈窗顯示更多內容，可以適度提高該值；如果希望介面更緊湊，則可以降低該值。

遊戲設置

預設API源

選擇預設的遊戲資源平台資料來源。可用選項：Modrinth 和 CurseForge。

顯示快照版

控制遊戲版本列表中是否包含快照版。

啟用後，建立遊戲或選擇版本時會顯示實驗性快照版本；關閉後，僅顯示一般正式版本。

整合包匯出格式

設定匯出整合包時預設使用的格式。可選項：CurseForge、Modrinth。

如果整合包準備發布到 CurseForge，請選擇 CurseForge 格式；如果準備發布到 Modrinth，請選擇 Modrinth 格式。

預設記憶體分配

設置全域預設記憶體範圍（Xms-Xmx）。

Java 運行時與重新安裝

當啟動器已在工作目錄中偵測到可用的 Java 運行時元件時，會在遊戲設置中顯示 Java 運行時區域。您可以在選單中選擇要操作的元件（例如不同版本線路所需的運行時）。

旁側的 輔助說明按鈕可檢視目前選中運行時的可執行檔路徑以及 java --version 輸出摘要。

重新安裝：針對目前選中的元件，啟動器會先刪除該元件在運行時目錄下對應的整個資料夾，再重新下載並安裝。過程中會開啟下載進度視窗；完成後關閉視窗，清單會自動重新整理。下載進行中時無法再次點選重新安裝。

【注】首次缺少某元件而由啟動器自動下載時，也會採用「先清空該元件目錄再安裝」的同一策略，以確保安裝結果一致。

同步語言到 options.txt

控制在建立新遊戲時，是否將啟動器目前語言自動同步到遊戲的 options.txt。

啟用後，新建立的遊戲實例會盡量預設使用與啟動器一致的語言設定。

遊戲資源資訊

顯示快取檔案數量和總大小（唯讀）。

清理快取

用於清理啟動器快取的遊戲資源檔案。

執行後可以釋放磁碟空間，但後續再次存取相關資源時，啟動器可能需要重新下載對應內容。

遊戲高級設置

遊戲高級設置為單個遊戲實例的獨立配置，只有在已選取某個遊戲後，對應標籤頁才會可用。

Java 路徑

自定義Java可執行檔案路徑，可重置為預設值。

以下是 MC 版本及其最低要求的 Java 版本：

  • 1.12 - Java 8

  • 1.17 - Java 16

  • 1.18 - Java 17

  • 1.20.5 - Java 21 (64-bit)

垃圾回收器

選擇垃圾回收器類型，根據Java版本自動過濾可用選項。

可用的垃圾回收器選項：

  • G1GC - Java 7+

  • ZGC - Java 11+

  • Shenandoah - Java 12+

  • Parallel - Java 1.0+

  • Serial - Java 1.0+

性能優化預設

選擇性能優化級別：

  • 停用 - 不啟用任何優化

  • 基礎 - 啟用基本優化

  • 平衡 - 啟用記憶體和執行緒優化（推薦）

  • 最大 - 啟用所有優化包括Aikar Flags（僅G1GC可用）

記憶體範圍

為目前遊戲單獨設定 Xms / Xmx 記憶體範圍（512 MB - 最大記憶體）。

此設定會覆蓋全域預設記憶體分配，僅對目前選取的遊戲生效。

自定義JVM參數

手動輸入JVM參數（與垃圾回收器和性能優化互斥）。

環境變數

設置遊戲運行時的環境變數。

玩家設置

玩家設置用於管理登入方式、皮膚站與認證服務等與帳號相關的行為。

無痕登入

控制是否在透過瀏覽器完成登入時使用無痕工作階段。

啟用後，微軟正版登入與第三方皮膚站（Yggdrasil）登入都會使用獨立的無痕瀏覽器視窗，不會與系統預設瀏覽器共享 Cookie。這有助於在同一台 Mac 上避免誤用已登入的瀏覽器帳號，但通常需要每次登入時重新輸入帳號和密碼。

關閉時，登入流程可能會複用系統瀏覽器中已有的登入狀態，操作較便捷，但隱私隔離較弱。

【注】此選項只影響登入時的瀏覽器行為，不會改變已保存的玩家檔案或權杖儲存方式。

離線登入

控制是否啟用離線登入功能。

啟用後，可以在不使用正版帳號登入的情況下建立和使用離線玩家檔案。

歷史皮膚庫

控制「歷史皮膚庫」入口是否在皮膚工具頁顯示，以及皮膚上傳成功後是否寫入歷史庫。

關閉後，皮膚工具頁將不再顯示歷史庫入口；同時新上傳成功的皮膚不會寫入歷史庫。

此開關不會自動刪除已保存的歷史記錄。若需清理，請在歷史庫彈窗中手動逐條刪除。

預設皮膚站 / Yggdrasil 伺服器

設定預設使用的皮膚站或 Yggdrasil 認證伺服器位址。

適用於需要接入第三方認證系統的場景，便於統一管理玩家檔案的登入來源。

authlib-injector

玩家設置頁會顯示 authlib-injector 的下載與狀態資訊。

當使用 Yggdrasil 等第三方認證服務時，啟動器可藉由 authlib-injector 提供相容支援。
