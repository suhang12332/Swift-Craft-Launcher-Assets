Launcher Settings

Swift Craft Launcher provides various configuration options to customize your experience.

General Settings

Language Selection

Select the application language. Changes require restarting the application to take effect. (You will be directed to System Settings, where the system manages the language preference.)

Supported languages: Arabic (ar), Danish (da), German (de), English (en), Spanish (es), Finnish (fi), French (fr), Hindi (hi), Italian (it), Japanese (ja), Korean (ko), Norwegian Bokmål (nb), Dutch (nl), Polish (pl), Portuguese (pt), Russian (ru), Swedish (sv), Thai (th), Turkish (tr), Vietnamese (vi), Simplified Chinese (zh-Hans), Traditional Chinese (zh-Hant).

Theme Selection

Select theme mode: System, Light, or Dark.

Interface Layout Style

Set the launcher's interface layout style. Available options: classic and focused.

classic fits a more traditional multi-panel layout, while focused emphasizes a cleaner and more content-focused experience.

Launcher Working Directory

Set the launcher's working directory. All game files managed by the launcher will be placed in this folder. Can be reset to default value.

Important: After changing the working directory, games in the original path will no longer appear in the "Game List". It is recommended to transfer or re-download them. It's best to change the working directory when first opening the launcher.

Concurrent Download Count

Set the number of concurrent downloads, range: 1-64. Higher concurrency can improve download speed but also brings greater performance overhead.

Global Sheet Height Limit

Set the maximum height limit for common Sheet panels in the launcher.

This helps control how tall modal panels appear on different screen sizes. Increase it to show more content, or lower it for a more compact layout.

Game Settings

Default API Source

Select the default game resource platform data source. Available options: Modrinth and CurseForge.

Show Snapshot Versions

Control whether snapshot versions are included in the game version list.

When enabled, experimental snapshot builds are shown while creating a game or choosing a version. When disabled, only regular release versions are shown.

Modpack Export Format

Set the default format used when exporting modpacks. Available options: CurseForge and Modrinth.

If you plan to publish the modpack on CurseForge, choose CurseForge format. If you plan to publish it on Modrinth, choose Modrinth format.

Default Memory Allocation

Set the global default memory range (Xms-Xmx).

Java Runtimes and Reinstall

When the launcher detects usable Java runtime components under your working directory, a Java runtimes section appears in Game Settings. Use the pop-up menu to choose which component to work with (for example, the runtime required by a specific Minecraft version line).

The Help button next to it shows the selected runtime’s executable path and a summary of the java --version output.

Reinstall: For the selected component, the launcher deletes the entire folder for that component under the runtimes directory, then downloads and installs it again. A download progress window opens during the process; after it finishes and the window closes, the list refreshes automatically. Reinstall is disabled while a download is already in progress.

Note: When the launcher first downloads a missing component automatically, it uses the same approach—clear that component’s directory first—so the install is consistent.

Sync Language to options.txt

Control whether the launcher's current language is automatically written into the game's options.txt when creating a new game.

When enabled, newly created game instances will try to use the same language as the launcher by default.

Game Resource Information

Display cache file count and total size (read-only).

Clear Cache

Clear cached game resource files managed by the launcher.

This can free disk space, but the launcher may need to download the same resources again later when they are needed.

Game Advanced Settings

Game Advanced Settings are per-game-instance settings. This tab is only available after a specific game has been selected.

Java Path

Customize the Java executable file path. Can be reset to default value.

Below are MC versions and their minimum required Java versions:

  • 1.12 - Java 8

  • 1.17 - Java 16

  • 1.18 - Java 17

  • 1.20.5 - Java 21 (64-bit)

Garbage Collector

Select garbage collector type. Available options are automatically filtered based on Java version.

Available garbage collector options:

  • G1GC - Java 7+

  • ZGC - Java 11+

  • Shenandoah - Java 12+

  • Parallel - Java 1.0+

  • Serial - Java 1.0+

Performance Optimization Preset

Select performance optimization level:

  • Disabled - No optimizations enabled

  • Basic - Enable basic optimizations

  • Balanced - Enable memory and thread optimizations (Recommended)

  • Maximum - Enable all optimizations including Aikar Flags (G1GC only)

Memory Range

Set a dedicated Xms / Xmx memory range for the current game (512 MB - Maximum memory).

This setting overrides the global default memory allocation and only applies to the currently selected game.

Custom JVM Arguments

Manually enter JVM arguments (mutually exclusive with garbage collector and performance optimization).

Environment Variables

Set environment variables for game runtime.

Player Settings

Player Settings are used to manage login behavior, skin site defaults, and authentication-related services.

Incognito Login

Controls whether sign-in uses a private browser session when authentication happens in the browser.

When enabled, both Microsoft premium login and third-party skin site (Yggdrasil) login use a separate incognito browser window and do not share cookies with your default system browser. This helps avoid accidentally using an already signed-in browser account on the same Mac, but you will usually need to enter your account and password again on each login.

When disabled, the sign-in flow may reuse an existing browser session, which is more convenient but offers less privacy isolation.

[Note] This option only affects browser behavior during login. It does not change how saved player profiles or tokens are stored.

Offline Login

Control whether offline login is enabled.

When enabled, you can create and use offline player profiles without signing in with a premium account.

History Skin Library

Controls whether the History Skin Library entry is shown in the Skin Tool page, and whether successfully uploaded skins are written to the history library.

When disabled, the history library entry is hidden in the Skin Tool page, and newly successful uploads are not saved to the history library.

This toggle does not automatically delete existing history data. To clean it up, remove entries manually in the history library pop-up.

Default Skin Site / Yggdrasil Server

Set the default skin site or Yggdrasil authentication server address.

This is useful when you use third-party authentication systems and want a unified default login source for player profiles.

authlib-injector

The Player Settings page displays authlib-injector download and status information.

When using Yggdrasil or other third-party authentication services, the launcher can rely on authlib-injector for compatibility support.
